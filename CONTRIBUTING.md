# Contributing to OpenMakerProjects

First off, thank you for considering contributing to OpenMakerProjects! It's people like you that make open-source hardware and firmware such a great community.

## 🛠️ How to Contribute

### 1. Reporting Bugs / Hardware Issues
If you find a bug in the firmware or an issue with a hardware schematic:
- Ensure the bug was not already reported by searching on GitHub under Issues.
- If you're unable to find an open issue addressing the problem, open a new one. Be sure to include your hardware setup (e.g., ESP32 model, sensor version), a clear description, and steps to reproduce.

### 2. Suggesting Enhancements
Got an idea for a new IoT module or an improvement to existing firmware?
- Open a new Issue describing the enhancement.
- Provide a clear use case and any potential hardware constraints.

### 3. Pull Requests
- **Fork the repository** and create your branch from `main`.
- **Hardware Tests:** If you've changed firmware, please verify it compiles and runs on the target microcontroller (e.g., ESP32, Arduino).
- **Code Style:** We primarily use C++. Please format your code consistently with the existing codebase.
- **Documentation:** If you add a new feature, update the README or relevant documentation.
- Open a Pull Request with a clear title and description.

## 🤝 Community
Join our discussions in the Organization Discussions tab to talk about projects, ask questions, and share your builds!
